1. Bootstrap 5 & Github Pages

The student was tasked with creating an E-Portfolio to be hosted online via a free website host of their choosing. For this task, the student decided to write their E-Portfolio website in HTML, using Bootstrap 5 and hosted via Github Pages.

Bootstrap is a popular open-source CSS framework, originally developed at Twitter in 2010, for developing responsive websites [1]. It provides a collection of design templates, CSS and JavaScript components and makes it easier to quickly produce a visually appealing and functional web sites [1].

Github Pages is a site hosting service that allows the user to upload their HTML, CSS and other site content to a Github repository and directly publish them as a website [2].
